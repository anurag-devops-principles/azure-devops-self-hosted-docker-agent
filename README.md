# azure-devops-self-hosted-docker-agent
A Cross-platform Docker-based Azure DevOps self-hosted agent with pre-installed DevOps tools, including Terraform, Azure CLI, Docker CLI, kubectl, Helm, TFLint, SonarQube Scanner, Java, Maven, Node.js, Python, and Git. Supports Windows and macOS via Docker Desktop, with Linux AMD64 and ARM64 architectures for consistent CI/CD automation.
